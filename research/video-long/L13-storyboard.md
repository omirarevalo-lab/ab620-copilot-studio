## Fact notes (checked)
- A custom prompt is a saved instruction for a model: instructions, inputs (and optional knowledge), single turn, one result — theory L13.
- Three places: agent tool (Tools, New tool, Prompt), topic node (Add a tool, New prompt), Run a prompt action in an agent flow — theory L13.
- Editor: instructions by hand, with Copilot, or from a template; clear and short; fallback output such as "not found"; test with sample data before using — theory L13.
- Temperature from zero to one, default zero; at zero more consistent; disabled (slider greyed) with the GPT-5 reasoning model; set in the prompt settings, not the agent settings — theory L13.
- Contoso case: prompt "Classify ticket", input ticket text, returns category (hardware, software, access) and urgency (high, medium, low), answers "not found" if too little info; temperature zero → five similar tickets same classification; used as an agent tool on every new request — theory L13 example.
