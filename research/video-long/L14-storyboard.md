## Fact notes (checked)
- Send HTTP request lets a topic call an API on the internet by itself, to read or change information outside the agent — theory L14 intro.
- Fields: URL, method (GET, POST, PATCH, PUT, DELETE), headers such as Authorization, body; default body No Content, typical for GET — theory "What you configure".
- Body: JSON content (JSON object, typical for POST or PUT); Edit JSON and Formula (Power Fx object with variables); Raw content (text string, Power Fx formula) — theory "The body".
- Response: Response data type, paste a sample JSON, Get schema from sample JSON, variable with that shape; Save user response as — theory "The response".
- Errors: default Raise an error, the agent stops and the On Error system topic fires; Continue on error saves status code and error body in variables and the topic goes on; error type Any, converted with Parse value; default timeout 30 seconds — theory "If something fails".
- Contoso case: GET to a tickets API, No Content, response from sample JSON; 404 with Continue on error → Topic.StatusCode, Topic.ErrorResponse, reply "I could not find that ticket" without stopping; POST with JSON content to create tickets — theory L14 example.
