## Fact notes (checked)
- A tool can be called explicitly from a topic or by the agent when it decides it needs it; driver with a fixed route versus one who chooses the way — theory L15 intro.
- Classic orchestration (generative orchestration off): the agent answers only with topics, tools are called only explicitly from a topic. Generative orchestration: the orchestrator picks the most suitable tool or topic by itself, reading its name and description — theory "Classic versus generative".
- Orchestrator definition: decides which topic, tool, or knowledge to use to respond — glossary.
- Trigger phrases only select topics, never tools; tools can be used inside topics; Add node, Add a tool, Action node appears — theory "Trigger phrases and tools".
- Tool details: Allow agent to decide dynamically; Ask the end user before running (confirmation, No by default); Authentication (end user or maker credentials); Fill using sets how the inputs are filled — theory "Tool settings".
- After running: Don't respond (default), Write the response with generative AI, Send specific response, Send an adaptive card; tools run in the user's context, so authentication must be enabled — theory "What happens when it finishes".
- Create search query and Perform custom search exist only inside topics, added with Add a tool, not on the Tools page, not callable by the orchestrator; Create search query rewrites the latest message plus context into a clear query string ("what about sick leave?"); Perform custom search returns raw, unsummarized results in a variable to filter, apply business rules or feed a prompt; often used in sequence; Generative answers finds and writes in one step — theory "Search tools that only work in topics".
- Contoso case: Check inventory, Ask the end user before running on because it can show stock data, end user credentials so each employee sees only what their account allows, description "checks stock by product code" — theory L15 example.
- Studio steps (scene 10 only those): Tools page, Add a tool, Add and configure, review Name and Description, Ask the end user before running, Add node (+) in a topic, Add a tool, Action node, test in the chat for confirmation — theory L15 steps.
- Exam distractors "By the user, from the chat window", "Authentication with maker credentials" and "Create search query" (for raw results) are wrong choices only; the video claims nothing about them beyond the theory. "On by default" for generative orchestration is NOT in the theory and is not said. No real URLs, product codes or limits.
