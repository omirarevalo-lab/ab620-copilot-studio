## Fact notes (checked)
- Agent flow = an automatic recipe of steps, like creating a ticket or sending an email; give it to the whole agent or place it at an exact point in a topic — theory L16 intro; glossary "Agent flow".
- A flow added to a topic is available only to that topic and runs exactly at the point on the canvas where you put it, like an Action node — theory "A flow in a topic"; glossary "Topic-level tool".
- Added from the agent's Tools page = agent-level tool; the orchestrator can pick it directly at run time, without a topic calling it — theory "A flow at agent level"; glossary "Agent-level tool".
- Allow agent to decide dynamically off = used only when a topic calls it explicitly; Ask the end user before running only asks for confirmation, the orchestrator can still pick it — theory "Controlling automatic selection"; exam tips.
- Requirements: When an agent calls the flow trigger, Respond to the agent action, published, real time, within 100 seconds; solution flow or not in the tool picker; created as a new tool from the agent, Copilot Studio adds trigger and response action — theory "Flow requirements" and "Long jobs".
- Respond to the agent = sync/async line; actions after it run asynchronously up to Power Automate's flow duration limit of 30 days; long work: return a job ID within 100 seconds, polling topic or follow-up message gives the final result — theory "Long jobs: the async split"; exam tip.
- Asynchronous response On: newer separate callback for flows longer than two minutes, only on new infrastructure, fully supported in Teams, not in Microsoft Copilot or telephony; not the tool pattern, keep it Off for a tool — theory "Long jobs".
- Contoso case: CreateTicket inside Report problem, after title and urgency, returns the ticket number in a message; Contoso does not want tickets in other conversations; if added as agent tool, Allow agent to decide dynamically off — theory L16 example.
- Studio steps (scene 9 only those): create and publish a simple agent flow; Topics page, open the topic; Add node (+) under the node; Add a tool, select the flow; Action node appears; map inputs to topic variables, outputs in a Message; if also an agent tool, turn off Allow agent to decide dynamically — theory L16 steps.
- Exam distractors "In all topics of the agent", "Remove the flow from the Report problem topic" and "Move every action before the response" are wrong choices only; the video claims nothing about them beyond the theory. The long job in scene 10 is generic; no real job durations, URLs or limits beyond 100 seconds, 30 days and two minutes.
