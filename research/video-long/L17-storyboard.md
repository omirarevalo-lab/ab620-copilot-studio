## Fact notes (checked)
- Agent flow = a sequence of automatic steps the agent can run, like a recipe with input ingredients and an output dish; it must start and end in a very specific way — theory L17 intro; glossary "Agent flow".
- Trigger When an agent calls the flow at the start, Respond to the agent at the end, the actions in between; other triggers belong to other scenarios such as Power Apps or schedules — theory "It starts and ends in a special way".
- Inputs defined in the trigger; with generative orchestration the agent fills them from the conversation context or generates questions to ask for them; a Custom value on an input means the agent no longer asks — theory "Inputs and outputs"; glossary "Custom value".
- Outputs defined in Respond to the agent; internal variables do not reach the agent; outputs appear as variables in the tool node of the topic or the orchestrator uses them to write the response — theory "Only the outputs arrive"; exam tip "only explicit outputs".
- Published, real time, Asynchronous response Off under Networking inside Respond to the agent, within the 100-second action limit; a newer separate callback with Asynchronous response On exists for long flows (over two minutes) but is not the tool pattern — theory "Conditions to use it"; glossary "Asynchronous response". The video says only "long flows" for the callback, no extra details.
- Contoso case: CreateTicket, inputs title and urgency, output ticketId; title from the message "my laptop will not turn on"; urgency as a fixed Custom value Medium so the agent no longer asks; the flow responds with ticketId and the agent shares it; published before it was added — theory L17 example.
- Studio steps (scene 9 only those): create a new agent flow (designer or natural language); check the trigger When an agent calls the flow; add inputs title and urgency; add the middle actions; Respond to the agent with output ticketId; Asynchronous response Off; publish and add from Tools, Add a tool, Flow — theory L17 steps.
- "A flow does not show up as a tool": trigger or Respond to the agent missing, not published, or Asynchronous response still on — exam tip; used for exam 3 (the right answer is publishing because the other three causes are ruled out in the question).
- Exam distractors "Add a Question node for urgency", "Remove urgency from the trigger", "Ask Nexo to read the flow variable", "Copy the variable into the topic" and "Set a Custom value on each input" are wrong choices only; the video claims nothing about them beyond the theory (a Question node asks the user, which is what the manager wants to stop).
