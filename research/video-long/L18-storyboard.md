## Fact notes (checked)
- Actions are the steps a flow performs, like the ingredients and tools of a kitchen; some come grouped by type and others come from connectors to other systems — theory L18 intro.
- Four groups: AI capabilities (generate text, process documents, Run a prompt, call an agent, respond to the agent), Human in the loop (approvals or information), Built-in tools (loops, conditions, data operations, dates, child flows), Connectors — theory "The action catalog"; glossary "AI capabilities", "Built-in tools".
- Connectors bring actions from other systems such as Dataverse; Run a prompt, in AI capabilities, runs a prompt at a point in the flow; added with Insert new action, choosing an existing or new prompt — theory "Connectors and Run a prompt"; exam tip "Run a prompt is in AI capabilities".
- By default a flow taking more than two minutes to respond to the agent fails; express mode speeds up flows with heavy processing and low data volume so they finish in that window; preview — theory "What express mode is (preview)"; glossary "Express mode". "Nexo gets an error" / "Marta waiting" is the spoken consequence of "fails" only.
- 100 seconds = action limit for a flow used as a tool; two minutes = default window for an agent flow to respond (the one express mode helps with); for a tool flow plan for 100 seconds — theory "What express mode is (preview)".
- Requirements: When an agent calls a flow trigger, Respond to the agent action, Copilot Studio plan; no extra cost. Limits: no Delay or webhooks; poor with lots of data; not more than about 100 actions per run; avoid very large connector responses — theory "Requirements and limits".
- Long processes are asynchronous and not for express mode (trap) — exam tips; theory L18 example (reconciliation).
- Contoso case: CreateTicket, Dataverse connector inserts the ticket row, Run a prompt summarizes the user text, ends with Respond to the agent; heavy processing, little data, express mode (preview) on, answers within two minutes; the long reconciliation process does not use it and works asynchronously — theory L18 example.
- Studio steps (scene 9 only those): open an agent flow; Insert new action; review the four groups; add a connector action (Dataverse); add Run a prompt from AI capabilities; Overview, Edit under Details, turn on Express mode (if available in the environment); test that it responds in under two minutes — theory L18 steps.
- Exam distractors "Look under the Connectors group", "Look under Built-in tools", "Turn on express mode for it", "Add a Delay action to it", "A Delay action before the end" and "A webhook that calls the agent" are wrong choices only; the video claims nothing about them beyond the theory (Delay and webhooks are not supported in express mode).
