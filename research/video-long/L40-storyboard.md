## Fact notes
- All facts come from the L40 theory (intro, sections, steps, example, examTips, glossary) and FACTS.md "Pipelines in Power Platform": automate the trip Dev → Test → Production; guided ALM without your own scripts; deploy managed solutions; same exported artifact through the stages in order, cannot skip QA; host stores artifacts and backups (theory visual); see and run from an unmanaged solution in the development environment, not from the default solution or from the targets; host = production environment, not necessarily managed; Developer environments need not be managed; all others must be Managed Environments; Managed Environment = extra Power Platform governance (glossary); one solution at a time; default import Upgrade; no cross-tenant deploy, use Azure DevOps or GitHub (example); connections, connection references and environment variables provided beforehand and validated before deployment; pre-deployment step trigger OnPreDeploymentStarted (20 complete, 30 reject); delegated deployments trigger OnApprovalStarted, run as a service principal (20 approve, 30 reject); the security team's manual approval and the rejected other-tenant attempt are from the theory example. Exam traps match the theory's traps: running from the default solution, thinking the host must be managed, confusing 20 and 30.
- Story details that are fiction, not product facts: the nursery, trays, trolley, governance panels, inspection gate, "Valeria almost skipped Test", the older managed copy in Test, "test address", and the exam situations. `ApiBaseUrl` comes from the L39 lesson; NexoCore and the security team come from the theory example. "Status one hundred" is a deliberately wrong distractor (it also appears as a wrong option in the lesson check).
- Not used on purpose (no source in theory, or beyond its scope): Deployment Pipeline Administrator/User roles, the Deployment Pipeline Configuration app, redeploying previous versions, pre-export step, `pac pipeline` CLI, the October 2026 warning for unmanaged targets, cross-geo settings, premium licensing details, the pipeline-owner option of delegated deployments.
